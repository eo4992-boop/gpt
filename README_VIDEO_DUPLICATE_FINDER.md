# 영상 중복 파일 찾기

Windows에서 여러 폴더의 영상 파일을 검색하고 파일 크기, 파일명 유사도, 영상 메타정보를 이용해 중복 후보를 찾는 간단한 GUI 프로그램입니다.

## 실행

1. Python 3.11 이상을 설치합니다.
2. `pip install -r requirements.txt`를 실행합니다.
3. `python video_duplicate_finder.py`를 실행합니다.

영상 메타정보를 읽으려면 [FFmpeg](https://ffmpeg.org/)의 `ffprobe`가 PATH에 있어야 합니다. `ffprobe`가 없더라도 파일 크기와 이름을 기준으로 검색은 계속됩니다.

## 현재 기능

- 여러 검색 폴더 선택
- 하위 폴더 포함 검색
- 주요 영상 확장자 자동 인식
- 파일 크기 비교
- 파일명 유사도 임계값(기본 90%) 설정
- ffprobe 기반 재생시간/해상도/코덱 비교
- 중복 후보 그룹 표시
- 선택 파일 삭제
- Windows 탐색기에서 파일 위치 열기

> 삭제는 현재 휴지통이 아닌 영구 삭제 방식입니다. 중요한 파일이 있는 경우 삭제 전에 반드시 확인하세요.

## 다음 개선 후보

- 동영상 썸네일 및 미리보기
- 휴지통으로 이동하는 안전한 삭제
