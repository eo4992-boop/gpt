# 영상 중복 파일 찾기

Windows에서 여러 폴더의 영상 파일을 검색하고 파일 크기, 파일명 유사도, 영상 메타정보를 이용해 중복 후보를 찾는 간단한 GUI 프로그램입니다.

## 중복 판정 기준

- **파일 크기가 같으면** 파일명이 완전히 달라도 후보로 비교합니다. 우선 파일 앞/뒤 일부의 SHA-256을 비교해 같은 내용인지 빠르게 확인합니다.
- **파일 크기가 다르면** 파일명 유사도가 기본 **90% 이상**인 경우에만 비교합니다. 파일명도 다르고 크기도 다르면 바로 제외합니다.
- 후보에 대해서는 재생시간, 해상도, 코덱 등 영상 메타정보를 추가로 확인합니다.
- 파일명 유사도는 설정에서 50~100%로 조정할 수 있습니다.

## Windows 실행 파일

GitHub Actions의 `test-and-build` 작업이 테스트를 통과하면 `VideoDuplicateFinder-Windows` 아티팩트로 `VideoDuplicateFinder.exe`를 생성합니다.

## 실행

### 실행 파일 사용

1. GitHub Actions에서 성공한 `test-and-build` 실행을 엽니다.
2. `VideoDuplicateFinder-Windows` 아티팩트를 내려받습니다.
3. ZIP을 풀고 `VideoDuplicateFinder.exe`를 실행합니다.

### Python으로 실행

1. Python 3.11 이상을 설치합니다.
2. `pip install -r requirements.txt`를 실행합니다.
3. `python video_duplicate_finder.py`를 실행합니다.

영상 메타정보를 읽으려면 FFmpeg의 `ffprobe`가 PATH에 있어야 합니다. `ffprobe`가 없더라도 파일 크기와 부분 해시를 이용한 동일 파일 탐지는 가능합니다.

## 현재 기능

- 여러 검색 폴더 선택
- 하위 폴더 포함/제외 선택
- 주요 영상 확장자 자동 인식
- 파일 크기 기반 후보 선별
- 파일명 유사도 임계값(기본 90%) 설정
- 부분 SHA-256 확인
- ffprobe 기반 재생시간/해상도/코덱 비교
- 중복 후보 그룹 및 판정 이유 표시
- 선택 파일을 Windows 휴지통으로 이동
- Windows 탐색기에서 파일 위치 열기
- GitHub Actions에서 자동 테스트 및 Windows 단일 실행 파일 빌드

> 삭제 기능은 영구 삭제가 아니라 Windows 휴지통으로 이동하도록 구성했습니다. 그래도 실제 파일을 선택할 때는 반드시 확인하세요.

## 알려진 제한

- 파일명이 완전히 다르고 파일 크기도 다른 재인코딩 영상은 의도적으로 비교하지 않습니다.
- 파일 크기가 같은 서로 다른 영상은 부분 해시와 메타정보로 보수적으로 걸러냅니다.
- `ffprobe`가 없으면 재생시간/해상도/코덱 기반의 추가 판별이 제한됩니다.
- 현재는 영상 내용을 프레임 단위로 비교하지 않으므로, 해상도 변경·재인코딩 등으로 크기가 달라지고 파일명까지 크게 달라진 영상은 찾지 않습니다.
