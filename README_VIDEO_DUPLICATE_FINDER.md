# 영상 중복 파일 찾기

Windows에서 여러 폴더의 영상 파일을 검색하고 **파일명 유사도 + 파일 크기**를 이용해 중복 후보를 찾는 간단한 GUI 프로그램입니다.

## 중복 후보 판정 기준

- 기본 파일명 유사도 임계값은 **80%**입니다. 50~100% 범위에서 변경할 수 있습니다.
- Windows 탐색기의 번호 복사 형식인 `파일명 (1).mp4`, `파일명 (2).mp4` 등의 끝부분을 제거한 뒤 파일명을 비교합니다.
- **파일 크기가 같고 파일명이 임계값 이상 유사하면 `강한 후보`**로 표시합니다.
- **파일 크기가 다르고 파일명이 임계값 이상 유사하면 `주의 후보`**로 표시합니다. 크기가 다르므로 실제 동일 파일이라고 단정하지 않습니다.
- 현재 버전은 영상 내용을 직접 비교하지 않으며, ffprobe·부분 SHA-256·재생시간·해상도·코덱 분석을 사용하지 않습니다.
- 따라서 결과는 **중복 후보**이며, 특히 `주의 후보`는 사용자가 파일 내용을 확인한 뒤 삭제해야 합니다.

## 결과 그룹화

후보 관계를 연결 그래프로 구성하여 그룹화합니다. 예를 들어 A-B와 B-C가 후보이면 A-C의 유사도가 낮더라도 같은 후보 그룹으로 표시될 수 있습니다.

각 그룹에서는 **가장 큰 파일을 `보존 권장`으로 표시**합니다. 이는 일반적인 품질 보존을 위한 참고 정보일 뿐이며, 프로그램이 원본 여부를 판정한다는 의미는 아닙니다.

## 삭제 안전장치

- 검색 결과의 삭제 체크박스는 **기본적으로 모두 해제**되어 있습니다.
- 프로그램이 파일을 자동으로 삭제하거나 자동 선택하지 않습니다.
- 삭제 대상과 전체 경로를 최종 확인 대화상자에서 다시 표시합니다.
- `보존 권장` 파일을 선택한 경우 추가 경고가 표시됩니다.
- 한 후보 그룹의 모든 파일을 삭제하도록 선택하면 삭제를 차단하고, 각 그룹에서 최소 1개 파일을 남기도록 요구합니다.
- 삭제는 영구 삭제가 아니라 `send2trash`를 통해 **Windows 휴지통으로 이동**합니다.

> 휴지통으로 이동된 파일도 사용자가 직접 복원할 수 있지만, 중요한 원본을 삭제하지 않도록 반드시 삭제 대상과 경로를 확인하세요.

## Windows 실행 파일

GitHub Actions의 `test-and-build` 작업이 테스트를 통과하면 `VideoDuplicateFinder-Windows` 아티팩트로 `VideoDuplicateFinder.exe`를 생성합니다.

## 실행

### 실행 파일 사용

1. GitHub Actions에서 성공한 `test-and-build` 실행을 엽니다.
2. `VideoDuplicateFinder-Windows` 아티팩트를 내려받습니다.
3. ZIP을 풀고 `VideoDuplicateFinder.exe`를 실행합니다.

### Python으로 실행

1. Python 3.11 이상을 설치합니다.
2. `pip install -r requirements.txt`를 실행합니다.
3. `python video_duplicate_finder.py`를 실행합니다.

## 현재 기능

- 여러 검색 폴더 선택
- 하위 폴더 포함/제외 선택
- 주요 영상 확장자 자동 인식
- 파일 크기와 파일명 유사도를 이용한 후보 탐지
- 파일명 유사도 임계값 50~100% 설정, 기본 80%
- Windows 번호 복사 이름 정규화
- 후보 그룹 및 판정 이유 표시
- 가장 큰 파일을 보존 권장으로 표시
- 삭제 대상 파일을 사용자가 직접 선택
- 후보 그룹의 전체 파일 일괄 삭제 차단
- 선택 파일을 Windows 휴지통으로 이동
- Windows 탐색기에서 파일 위치 열기
- GitHub Actions에서 자동 테스트 및 Windows 단일 실행 파일 빌드

## 테스트 범위

현재 자동 테스트는 다음을 포함합니다.

- Windows 번호 복사 이름 정규화
- 동일 크기 + 유사 파일명 후보
- 다른 크기 + 유사 파일명 주의 후보
- 무관한 파일명 제외
- 유사도 임계값 변경
- 연결된 후보 관계의 그룹화
- 그룹 내 가장 큰 파일 우선 정렬
- 크기가 다른 파일을 실제 동일 파일로 단정하지 않는 판정 문구

## 알려진 제한

- 파일명과 크기만으로는 영상 내용이 실제로 같은지 확정할 수 없습니다.
- 같은 이름이라도 내용이 다른 영상이 있을 수 있으며, 특히 크기가 다른 `주의 후보`는 반드시 사용자가 확인해야 합니다.
- 파일명이 크게 다르거나 재인코딩으로 크기가 달라진 동일 영상은 찾지 못할 수 있습니다.
- 대규모 폴더에서는 파일명 비교 자체에 시간이 걸릴 수 있습니다. 비교 과정에서는 `SequenceMatcher.quick_ratio()`를 이용해 명백히 낮은 후보를 먼저 제외합니다.
- 현재 버전에서는 ffprobe, SHA-256, 영상 프레임 비교를 사용하지 않습니다.
